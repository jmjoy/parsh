# parsh

[English](README.md) | 简体中文

parsh 意为 **parenthesis shell**。

一个命令行与脚本共用同一种 Lisp 方言的 Linux Shell。普通用户的提示符是 `$ ()`，root 为 `# ()`，
输入 `echo hello` 并按 Enter 即可执行 `(echo hello)`；Ctrl+J 强制换行。

目前是早期实现，版本为 `0.1.0`。

## 对 AI 友好

Shell 脚本常常把逻辑分给 `awk`、`sed` 或内联的解释器，每多一层就多一套引号规则要处理。
parsh 把逻辑留在脚本里：算术、列表与映射、函数和循环像通用脚本语言一样可用，
外部命令、管道与重定向则共用同一套语法。值不会被隐式拆词，也不会被悄悄做通配符展开，
脚本写的是什么，执行的就是什么 —— 这正是生成的脚本容易读、容易审阅、容易修的原因。

```parsh
(let count (+ (| (find . -name "*.rs") (wc -l)) 0))
(echo "rust files: $count; doubled: $(* $count 2)")
```

后续计划支持引入库，届时脚本可以像 Python 模块那样复用现成的代码。

## 运行

```console
cargo run
cargo run -- -c '(echo hello)'
cargo run -- examples/hello.parsh world
```

不带参数启动时，如果标准输入是终端，parsh 会打开交互编辑器；否则从标准输入读取脚本。
`parsh -` 可以显式指定从标准输入读取。另提供 `--help` 和 `--version`。
脚本参数通过列表 `$args` 获取，其中不包含脚本文件名。
将可执行文件加入 PATH 后，脚本可以使用 `#!/usr/bin/env parsh` 作为首行。

命令行选项由 clap 解析。脚本路径或 `-c SOURCE` 之后的所有参数都会原样传入脚本，
包括 `--help` 和 `--`。如果脚本文件名以 `-` 开头，可使用 `parsh -- -script.parsh`。

更多可运行脚本见[示例目录](examples/README.zh-CN.md)，涵盖变量、函数、循环、管道和文件操作。

## 变量与值

在值的位置，裸词表示文本：`123`、`true`、`false` 和 `nil` 都没有特殊的字面量含义。
双引号字符串支持 `$name` 和 `$(...)` 插值，以及 `\"`、`\\`、`\n`、`\r`、`\t` 和 `\$` 转义。
单引号字符串完全保留原文，不插值也不处理转义。`${name}` 保持为普通文本。
三引号字符串 `"""..."""` 和 `'''...'''` 保留换行与缩进；三重双引号支持相同的插值和转义，
三重单引号完全保留原文。
读取变量值时使用 `$name`；绑定和赋值目标使用裸名字，包括函数参数、循环绑定和环境变量设置。
变量名以字母或 `_` 开头，后续可包含字母、数字和 `_`。绑定目标不接受引号字符串或表达式。

所有普通数据采用值语义。读取变量、赋值和函数传参都会复制值，包括列表、映射及其嵌套内容。
集合更新返回新值，使用 `set` 显式赋回才会更新已有变量。

```lisp
(let name "a friend")
(echo hello $name)
(set name world)
(echo "hello, $name")
(echo "sum=$(+ 1 2)")
(echo 'literal $name and $(pwd)\n')
(echo """hello, "$name"
sum=$(+ 1 2)""")
(echo '''literal '$name'
$(pwd)\n''')
(export EDITOR vim)
```

`let` 在当前词法作用域中绑定变量。`set` 更新最近的已有绑定，或已有的环境变量；
名称未定义时会报错。查找不到局部变量时，会继续查找继承的环境变量。
`export` 为后续子进程设置环境变量，并更新已有的同名局部绑定。
环境变量与工作目录的修改属于当前 parsh 会话。

`(get name)` 是 `$name` 的函数形式：接受一个文本变量名，按相同规则查找并返回原始类型的值。
需要明确变量名边界时，使用 `"$(get name)_suffix"`。`$(name)` 调用名为 `name` 的零参数函数或命令；
插值支持所有现有表达式，包括嵌套调用和命令输出捕获。各片段从左到右求值一次，按 `str` 的规则
转换标量；nil 转为空文本，列表和映射报错。整个结果保持为一个参数，插入的值不会再次解析。
传给其他程序的字面 `$` 使用 `\$` 或单引号保留。单引号现在是字符串边界，含单引号的词需用双引号包裹。

```lisp
(let files (list "a file.rs" other.rs))
(printf "<%s>\n" $files)
(for file (glob *.rs)
  (echo $file))
```

列表作为外部命令参数时会展开一层。文本始终保持为一个参数，即使其中包含空格或换行。
`list` 构造列表，`str` 拼接标量值。`glob` 显式匹配文件，返回排序后的路径列表，
没有匹配项时返回空列表。普通裸词、字符串和变量值都不会隐式进行通配符展开、分词或波浪号展开。

`[a b]` 是 `(list a b)` 的简写，`[]` 创建空列表。
`{name parsh}` 是 `(map name parsh)` 的简写，`{}` 创建空映射。
两种形式可以嵌套，例如 `[one {items [two three]}]`。元素以空白分隔，映射使用交替的键和值。
包含 `[]` 或 `{}` 的文本和 glob 模式需要加引号，例如 `(glob 'file[12].txt')`。

`cd` 接受一个路径，不提供路径时使用 `$HOME`，并更新 `$PWD` 和 `$OLDPWD`。
相对命令路径、glob 模式和重定向路径均以当前工作目录为基准。

## 映射

`map` 接受交替的文本键和值，`(map)` 创建空映射。键和值从左到右各求值一次；
重复键会报错，不再求值该键对应的值表达式。值可以包含列表和嵌套映射。

```lisp
(let config (map name parsh version #1))
(let updated (mset $config name new-name))
(mget $config name)
(mget $updated name)
(mget $config missing fallback)
(mkeys $config)
(set config (mdel $updated version))
```

所有 `m` 命令的首参都是映射值，可以是 `$config`、映射字面量或返回映射的表达式。
裸词 `config` 表示文本，会报类型错误。上例中 `updated` 包含新名字，
`config` 保持原值，直到最后的 `set` 才更新。

| 命令 | 结果 |
| --- | --- |
| `(mget $config key)` | 返回原始类型的值；缺键时报错 |
| `(mget $config key default)` | 总会求值 `default`，缺键时返回它 |
| `(mset $config key value)` | 返回新增或覆盖该值后的新映射 |
| `(mdel $config key)` | 返回删除该键后的新映射；缺键时报错 |
| `(mhas $config key)` | 返回键是否存在的布尔值 |
| `(mkeys $config)` | 按插入顺序返回键列表 |
| `(mvals $config)` | 按相同顺序返回值列表 |
| `(mlen $config)` | 返回整数条目数 |

先检查参数个数，再从左到右各求值一次。`mget` 求值全部实参后检查映射并选择结果；
其余映射操作在首参通过映射类型检查后才继续求值后续参数。
更新操作使用这份独立值；后续参数即使修改来源变量，也不会改变已经取得的映射。
已有 nil 值的键仍然存在，返回 nil；显式默认值仍会求值。

映射操作可以直接组合，例如 `(mget (mset {name parsh} name other) name)` 返回 `"other"`。

覆盖已有键保留原位置；新增或删除后重新插入的键追加到末尾。
映射显示为 `(map "name" "parsh")`，`eq` 比较内容时忽略插入顺序。
`mset` 和 `mdel` 返回独立的新映射，输入值及其其他副本保持原值。
映射不能隐式转换为文本、外部命令参数或环境变量值。

## 标量字面值

使用 `#` 构造有类型的标量：`#1` 是 int，`#1.0` 和 `#1e3` 是 float，
`#true`、`#false` 是 bool，`#nil` 是 nil。普通的 `1`、`false`、`nil` 仍是文本。例如：

```lisp
(let config {retries #3 timeout #1.5 enabled #false})
(list (typeof #1) (typeof 1) (eq #1 1))
```

列表显示为 `("int" "text" #false)`。数字和布尔结果显示时带 `#`，包括集合中的元素；
集合中的 nil 显示为 `#nil`，顶层 nil 结果继续静默。
`str`、字符串插值、外部参数和环境变量使用不带前缀的文本：`(str #1 #false)` 返回 `"1false"`。

所有以 `#` 开头的裸词都已保留，`#flase`、`#123abc` 和单独的 `#` 均为读取错误。
文本需要加引号，例如 `"#fff"`；`abc#1` 仍是普通文本。源码最开头的 shebang 保持有效。
结构化注释中不校验 `#` 字面值，但继续检查字符串结构和括号配对。
字面值必须连续书写。数字沿用正负号、十进制、小数和指数语法，使用 i64 整数与有限 f64；
整数溢出不会改为浮点数。布尔和 nil 名称仅接受完整小写写法，不提供 `#t`、`#f` 别名。

提示符和脚本顶层可以直接书写字面值，脚本不会自动打印其结果。
字面值是源码语法：引号文本、变量内容和命令输出不会重新解析，`#$name` 不是转换操作。
动态转换使用 `int`、`float`、`bool`。

调用头只接受文本命令名或函数值。`(#1)` 以及数值变量作为命令名都会报错；
需要文本命令名时显式使用 `str`。`#false` 是普通假值，`(false)` 保持外部命令的失败行为。
数字和 nil 不会隐式变成条件。

## 标量转换

每个转换函数恰好接受一个参数，先检查参数个数，再求值一次。
函数引用与 `apply` 使用相同规则。`int`、`float`、`bool` 是保留的普通内建命令名。

| 调用 | 接受的输入与结果 |
| --- | --- |
| `(int value)` | int、i64 范围内没有小数部分的 float，或按现有规则解析的数值文本。`(int "1e2")` 返回 `#100`，`(int #1.5)` 报错。 |
| `(float value)` | int、float，或直接按 f64 解析的数值文本。允许正常舍入，包括大整数精度损失；拒绝非有限结果。 |
| `(bool value)` | bool，或去掉首尾空白后恰好为小写 `true`、`false` 的文本。数字、nil 和其他类型报错。 |

数值文本去掉首尾空白后必须完整解析。`int` 遇到带小数点或指数的文本时，先解析成 f64，
再按舍入后的值判断是否为整值。整数文本必须在 i64 范围内；
`(float "9223372036854775808")` 则可以直接解析成有限浮点数。
布尔值不能转为数字，集合、表单、函数、nil 和命令状态都不是转换输入。
文本 `"#1"`、`"#false"` 不会重新按字面值读取。错误指向操作数，退出码为 `2`。

```lisp
(int " 1.0 ")
(float #1)
(bool " false ")
(apply (function int) ["1e2"])
```

结果依次为 `#1`、`#1.0`、`#false`、`#100`。

## 四则运算与比较

裸词继续表示文本。算术运算符 `+`、`-`、`*`、`/` 和比较运算符
`=`、`!=`、`<`、`<=`、`>`、`>=` 接受数值或数值文本，
包括变量和捕获的命令输出。算术返回数值；普通文本 `00123` 仍保留原样。

```lisp
(let count (+ 001 2))
(+ $count 1)
(/ 5 2)
(eq $count 3)
(= $count 3.0)
(str 00123)
```

绑定之后，交互环境依次显示 `#4`、`#2.5`、`#false`、`#true` 和 `"00123"`。
`eq` 比较类型和值，文本、整数和浮点数互不相同。
`=` 比较数值，包括数值文本；它恰好接受两个参数，不引入浮点比较容差。

`!=` 判断数值不相等；`<`、`<=`、`>`、`>=` 分别判断小于、小于等于、大于、大于等于。
每个比较运算符恰好接受两个参数，返回布尔值。即使大整数与浮点数混合比较，也保留整数精度。

```lisp
(> 10 2)
(>= 3 3.0)
(< 9007199254740992.0 9007199254740993)
(!= 1 1.5)
(if (<= $count 3) (echo "at most three"))
```

参数从左到右各求值一次，算术运算左结合。`+`、`*` 支持任意数量的参数，
`(+)` 返回整数 `0`，`(*)` 返回整数 `1`。
`-`、`/` 至少接受一个参数，单参数分别表示取负和取倒数。除法始终返回浮点数。

数值文本去掉首尾空白后完整解析，支持正负号、十进制整数、小数和科学计数法。
前导零按十进制处理，整数文本必须在 `i64` 范围内。布尔值、nil、列表和映射不能参与运算。
整数加减乘保持精确并检查溢出；每步运算遇到浮点数时使用 `f64`，
可能损失大整数精度，也有普通浮点舍入误差，例如 `(+ 0.1 0.2)` 返回
`0.30000000000000004`。非法操作数、除零、整数溢出和非有限浮点数均为语言错误，退出码为 `2`。
数值显示带 `#`，浮点数保留小数点或指数，例如 `#4.0`。
`str`、命令参数和环境变量使用不带 `#` 的数值文本。文件和 `-c` 脚本需要用 `echo` 等命令显式打印结果。

## 基础库

`and/or` 从左到右短路，仅接受布尔值或命令状态并返回布尔值；`(and)` 为真，`(or)` 为假。
列表操作使用 `l` 前缀，字符串操作使用 `s` 前缀，均返回新值：

```lisp
(let items (ssplit "a,b,c" ","))
(lappend $items [d e])
(lconcat $items [d e])
(lget $items -1)
(sjoin (lslice $items 1) " / ")
(list (quot -7 3) (rem -7 3) (round 2.5) (round -2.5))
(list (typeof 123) (typeof #123) (number? #123) (empty? []))
```

字符串按 Rust `chars()` 计数，索引和切片支持负数，切片越界截断。
`mget/lget/lfirst/sget` 的显式默认值始终作为普通实参求值，命中时也会执行并传播错误。
函数声明的 `&optional` 默认表达式仅在缺参时求值。
完整接口见[基础库参考](website/src/content/docs/zh-cn/docs/stdlib.md)，可运行示例见
[stdlib.parsh](examples/stdlib.parsh)。

## 结构化注释

```lisp
(; 这是一个完整的注释表达式。
   (; 注释可以嵌套。 )
   (no-such-command $undefined)
)

(echo (; 这个注释不会产生参数。 ) hello)
(echo ; this;is;text)
```

首个裸词为 `;` 的列表会被 reader 丢弃，无论它出现在什么位置。
注释内容仍遵循字符串与括号配平规则，但不会求值，也不会检查名称是否已定义。
其他位置的 `;` 都是普通文本；没有行注释。带引号的 `";"` 不是注释标记。

## 命令与组合

命令依次查找内置形式、宏、结构体构造器与成员、命名函数，以及 PATH 中的程序。
外部程序直接启动，表达式不会交给另一个 Shell 解析。
命令名也可以来自文本变量，例如 `($EDITOR file.txt)`；
变量值作为一个完整的程序名使用，不会隐式拆分出参数。

使用 `type` 查询命令的解析结果，不会执行被查询的命令：

```lisp
(type type cd echo)
(defn greet (name) (echo hello $name))
(type greet)
(type -a echo)
(let kind (type -t greet))
(if (type -t optional-tool) (optional-tool))
```

`type` 接受多个名称，也支持列表参数，并提供类似 Bash 的选项：

- `-a`：显示所有匹配，包括按 PATH 顺序找到的所有可执行文件路径。
- `-t`：对每个匹配输出 `builtin`、`macro`、`struct`、`function` 或 `file`。
- `-p`：输出外部命令路径；内建形式、宏、结构体和函数不输出内容。
- `-P`：强制搜索 PATH，即使存在同名内建命令或函数。
- `-f`：跳过函数、宏和结构体查找。

选项可以组合，`--` 表示选项结束。不带参数时静默成功。
找不到名称时状态为 `1`，非法选项的状态为 `2`。
输出支持捕获和重定向。浏览器终端按宿主提供的命令名称识别外部命令，
`-p` 和 `-P` 返回这些名称。

```lisp
(echo (pwd))
(| (find . -name "*.rs") (sort))
(|> files.txt (| (find . -name "*.rs") (sort)))
(|>> log.txt (echo another entry))
(<| input.txt (sort))
(|2> errors.txt (grep needle missing.txt))
```

组合操作如下：

- `|`：将外部命令连接为管道。
- `|>`、`|1>`：创建或清空文件，并将标准输出重定向到该文件。
- `|>>`、`|1>>`：创建文件或追加内容，并将标准输出重定向到该文件。
- `<|`：从文件读取标准输入。
- `|2>`：创建或清空文件，并将标准错误重定向到该文件。
- `|2>>`：创建文件或追加内容，并将标准错误重定向到该文件。

重定向始终将路径作为第一个参数、表达式作为第二个参数。
重定向形式可以嵌套，也可以包裹整个管道。
首版管道的每个阶段必须是外部命令调用；函数和改变 Shell 状态的内置形式在管道外执行。

例如，将标准输出写入清空后的日志，并将标准错误追加到另一个日志：

```lisp
(|1> output.log
  (|2>> errors.log
    (make)))
```

顶层命令实时输出。外部命令或管道用作值时，会将标准输出按 UTF-8 捕获，
移除末尾的 LF 换行符，并将结果保持为一个参数。标准错误仍写入原来的目标。
二进制输出应使用管道或文件重定向。显式重定向优先于对该表达式输出的捕获。

## 控制流与函数

```lisp
(defn greet (name)
  (echo hello $name))

(if (test -d src)
    (greet developer)
    (echo missing))

(if (eq $EDITOR vim)
    (echo using vim))

(if (not (test -f config.txt))
    (echo configuration missing))

(do
  (let message "multiple expressions")
  (echo $message))
```

`if` 只对选中的分支求值。条件必须产生布尔值（来自 `eq`、数值比较或 `not`）或命令退出状态；
退出状态为零表示真。文本和数值不会隐式转换为布尔值。
`do` 在当前作用域中依次执行表达式。
`for` 对列表求值，并为每次迭代创建新的词法绑定。

`while` 在每轮开始前检查条件。两种循环都接受一个或多个循环体表达式，并在每轮创建
独立作用域：`let` 的绑定留在本轮中，`set` 可以更新外层绑定。

```lisp
(let count #0)
(while (< $count 5)
  (set count (+ $count 1))
  (if (= $count 2) (continue))
  (if (= $count 4) (break (list stopped $count)))
  (echo iteration $count))
```

`(continue)` 跳过本轮剩余表达式。`(break)` 结束最近一层循环；`(break 值)` 对值求值一次，
并将其作为循环返回值，支持数值、列表、映射、布尔值和 `nil`。没有显式指定退出值时，循环返回
最近一次完整迭代的结果；没有完整迭代则返回 `nil`。被跳过或提前结束的迭代不会覆盖此前结果。
上述示例输出 `iteration 1` 和 `iteration 3`，并返回 `("stopped" #4)`。

循环跳转不能跨越函数边界。在当前函数没有活动循环体时使用会报错。循环条件或列表表达式
在自身循环体之外执行，其中的跳转只作用于已有的外层循环。`while` 循环体中的命令失败
会立即停止执行，即使整个循环被用作条件也是如此。

函数名和参数声明使用裸名字；读取参数和局部变量的值时使用 `$name`。
函数捕获定义时的词法作用域，并返回最后一个表达式的值。
参数表达式在绑定形参之前求值。函数既可以返回命令输出，也可以返回数值、列表、映射和布尔值。
函数用作值时，会捕获整个函数体的标准输出：如果最后一个表达式产生命令退出状态，
则返回捕获的输出文本；否则直接返回最后一个表达式的值，此前捕获的输出不再显示。

普通命令返回非零退出状态时，当前脚本或交互提交批次停止执行。
条件位置允许检查非零退出状态，但程序不存在等启动错误仍会导致失败。
管道返回最右侧失败阶段的非零退出状态，即使最后一个阶段成功也一样，包括上游因 SIGPIPE 退出的情况。
所有阶段的子进程都会被回收。
`exit` 接受 0 到 255 的退出码，并立即退出，即使它位于函数或嵌套表达式中；默认退出码为 0。

## 函数值与参数

`fn` 创建匿名函数，`function` 显式取得命名函数或普通内置函数的值。
函数值可以保存在集合中、传参或返回，并支持表达式作为调用头：

```lisp
(let inc (fn (x) (+ $x 1)))
($inc 2)
((fn (x) (* $x 2)) 3)
(let add (function +))
(apply $add 1 [2 3])

(defn sum (first &optional (second #0) &rest more)
  (let result (+ $first $second))
  (for n $more (set result (+ $result $n)))
  (return $result))
(sum 1 2 3 4)
```

参数顺序为必选参数、`&optional`、`&rest name`。可选参数可以只写名字，缺省为 nil；
`(name default)` 的默认表达式仅在缺参时、每次调用中求值，可以访问前面的参数和捕获环境。
可选参数按位置依次消费实参，剩余实参组成 rest 列表；列表实参保持为一个完整值。
`apply` 将最后一个列表展开为实参，并允许在列表前提供固定实参，所有值都不会再次解析或求值。

普通数据继续采用值语义；复制函数值保留相同的函数身份和捕获环境。
`eq` 按函数身份比较；函数引用保留取得时的定义，后续重定义不会改变已有引用。
闭包读取定义处的词法作用域，外层 `set` 的更新仍可见。函数值显示为 `<function name>`，
不能隐式转为文本、外部命令参数或环境变量。
`function` 不接受宏、外部命令或 `if`、`and`、`let` 等特殊形式。
`get`、`not`、数值与集合操作，以及 `glob`、`cd`、`type` 等普通内置支持函数引用。

`(return)` 提前返回 nil，`(return expr)` 求值一次并退出当前函数；可以穿过循环、
嵌套表达式和重定向，不会退出调用方函数。在函数外使用会报错。
命令表达式作为返回值时沿用普通值位置的输出捕获规则。
宏体也可用 return 提前返回表单；宏展开代码中的 return 则作用于调用方函数。

## 结构体

`defstruct` 定义结构体类型及其字段，同时生成构造器、每个字段一个访问器，以及一个判定：

```lisp
(defstruct Point x y)
(let point (Point #1 #2))
(echo (Point.x $point) (Point.y $point))
(if (Point? $point) (echo a point))
```

结构体按字段顺序显示，例如 `(Point #3 #4)`；字段是文本时保留引号，显示为 `(Point "3" "4")`。
它按名字与字段比较，并且和其他值一样按值拷贝。
访问器从值本身读取字段，因此重定义结构体不会让已有的值失效。
`type` 可以查看这些成员，不会执行它们：

```lisp
(type Point)
(type Point.x)
(type -t Point)
```

每个成员各占一个名字：`Point` 负责构造，`Point.x` 读取字段，`Point?` 判断类型。
结构体不可变，修改字段需要重新构造。

## 宏

`defmacro` 定义一种命令，它的参数以“被引用的表单”传入。反引号开始一个模板，
`,` 插入一个求值后的表达式，`,@` 把一个列表表单摊平到外层调用里：

```lisp
(defmacro unless (condition body)
  `(if (not ,$condition) ,$body))

(unless (test -f config.txt)
  (echo "configuration missing"))
```

宏体每次调用执行一次，必须返回被引用的表单；随后 Shell 在调用方的作用域里求值该表单，
所以返回模板中的 `$name` 读取的是调用方的变量。引用本身是普通值：表单按源码显示，
`eq` 按语法比较。

```lisp
(quote (a b))
(eq (quote (a b)) (quote (a   b)))
(defmacro begin (body) `(do ,@$body))
(begin ((echo one) (echo two)))
```

宏参数与 `defn` 一样支持 `&optional` 和 `&rest`；rest 收集未求值的表单列表，可用 `,@` 拼接。
宏不能出现在管道阶段；嵌套的 quasiquote 会原样拷贝。
定义是全局的，即使写在函数体内也一样。

## 交互编辑与粘贴

- 普通用户的提示符为 `$ ()`，root 为 `# ()`，光标位于右括号前。
  原生终端按有效用户 ID 判断，网页使用 `$ ()`。空输入时括号为灰色；开始输入后，
  隐含左括号恢复原色。前缀和灰色右括号提示只参与显示，不写入源码或历史。
- 首个非空白字符为 `#` 时，隐藏隐式括号并直接编辑字面值。字面值历史的光标位于末尾；Tab 补全 `#true`、`#false`、`#nil`。
- Enter 检查整个编辑区，与光标位置无关。源码已完整时直接执行；否则尝试在末尾
  补一个 `)`，能使整份源码完整才执行。仍未完成时，在光标处插入换行。
  Ctrl+J 始终换行。空白输入不执行、不写历史，也不改变退出状态。
- 手动输入 `)` 只编辑文本。新输入以 `(` 开头时切换到显式源码模式，
  完整表达式或脚本自身的括号只显示和读取一次。
- 粘贴只插入文本，其中的换行与制表符保持原样，不会执行命令。按 Enter 提交时，
  所有顶层表达式先通过语法检查，再按顺序执行。语法错误会报告位置，保留草稿和
  撤销记录供修改；源码未完成时继续编辑，不会先执行前面的完整表达式。
- 运行失败会停止本次提交的后续表达式，已经产生的效果保留。Ctrl+C 取消当前任务
  和该批次剩余命令。队列源码保留在 parsh 中；交互式子进程读取后续终端输入，
  不会读取队列中的命令。
- 方向键、Home/End、Backspace/Delete、Ctrl+A/E 和 Ctrl+U/K 用于编辑文本。
  编辑与显示会考虑 Unicode 字素簇及字符宽度。
  Up/Down 在行间移动，并在编辑区边界调取会话历史；Ctrl+P/N 始终用于浏览历史。
- Tab 补全内置命令、已定义函数、可执行程序、文件路径和 `$变量名`。
  唯一匹配直接补全，目录以 `/` 结尾；多个匹配先补公共前缀，再按 Tab 显示候选。
  补全作用于光标所在词，支持带引号的路径，不会执行命令。
  `cd` 只补目录，隐藏文件需要输入 `.` 前缀；字符串内不展开变量，结构化注释中不补全。
  粘贴中的制表符保持原样。
- 历史记录保存每条已执行顶层表达式的完整源码。调取时完整显示括号，光标停在
  最外层右括号前。可直接追加参数，或按 Enter 重新执行；
  向下浏览回到原草稿时，草稿原样恢复。
- Ctrl+C 清空输入或中断前台任务。编辑区为空时 Ctrl+D 退出，否则删除光标后的字符。

### Emacs 风格快捷键

原生终端和网页体验终端共用以下编辑命令。Alt 组合键也可以先按 Esc，再按对应键。
字符编辑以 Unicode 字素簇为单位；Home/End、Ctrl+A/E 和 Ctrl+U/K 作用于当前逻辑行。

| 按键 | 操作 |
| --- | --- |
| Ctrl+J | 强制插入换行，不执行 |
| Ctrl+B/F、Ctrl+H | 向左/右移动；向前删除 |
| Alt+B/F | 移到上一个词的开头/下一个词的末尾 |
| Ctrl+W | 向后剪切，空白分隔词 |
| Alt+Backspace、Alt+D | 向后/向前剪切，字母数字组成词，路径标点和下划线是分隔符 |
| Ctrl+U/K | 剪切到行首/行尾；行尾处 Ctrl+K 剪切换行符 |
| Ctrl+Y、Alt+Y | 粘回剪切内容；紧接着轮换此前剪切的内容 |
| Ctrl+T | 交换相邻字素簇；行尾交换最后两个，不跨越换行 |
| Ctrl+L | 清屏并重绘，保留草稿和会话 |
| Ctrl+R/S | 向后/向前增量搜索会话历史 |
| Ctrl+_、Ctrl+X Ctrl+U | 撤销一组编辑 |

连续剪切会按方向合并到同一条剪切记录，移动或其他编辑命令结束合并。
剪切记录跨命令保留，重置会话时清空；Alt+Y 仅紧接 Ctrl+Y 或 Alt+Y 时有效。
粘回、交换和撤销只编辑文本，其中的 `)` 不会自动执行命令。

搜索区分大小写，按完整历史源码匹配子串，不循环；输入或粘贴更新查询，Backspace 删除一个字素簇。
再次按 Ctrl+R/S 查找上一个/下一个匹配项；空查询时再次按下会复用上次查询。
未匹配时显示失败提示并保留上次预览。Enter 或 Esc 接受结果并回到编辑，不执行也不插入换行；
之后再按 Enter 执行。Ctrl+G 恢复搜索前的草稿和光标；其他编辑命令接受结果后继续操作，
Ctrl+L 保留搜索，Ctrl+C 取消输入。

连续打字按组撤销；删除、剪切、粘回、交换、补全和未提交的粘贴各自是一组。
移动光标结束打字分组；历史切换、搜索确认和提交建立新基线，中断或清空输入也会清空撤销记录。
撤销不会恢复已经执行的命令或其副作用。

网页快捷键只在终端聚焦时生效。浏览器或操作系统保留的组合键可能无法交给页面；
Alt 键冲突时可使用 Esc 前缀。复制和粘贴继续使用浏览器的快捷键。

错误信息包含来源、行号和列号。脚本执行时会恢复多余顶层 `)` 的错误，并继续执行后续表达式。
这类错误会使脚本以状态码 2 退出，除非后续的运行失败或显式 `exit` 指定了其他退出状态。
命令失败保留其退出状态；程序不存在时使用 127，没有执行权限时使用 126，其他语言错误使用 2。

首版面向 Linux 前台任务，包括交互式外部程序和前台管道。
暂不支持后台作业表、`bg`、`fg` 或挂起与恢复；子进程忽略 Ctrl+Z。
历史记录仅在当前会话中保留。持久化配置留待后续实现。
