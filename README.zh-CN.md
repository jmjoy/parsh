# parsh

[English](README.md) | 简体中文

parsh 意为 **parenthesis shell**。

一个命令行与脚本共用同一种 Lisp 方言的 Linux Shell。提示符是 `(`，
输入 `echo hello)` 即可执行 `(echo hello)`；Enter 用于换行。

目前是早期实现，版本为 `0.1.0`。

## 运行

```console
cargo run
cargo run -- -c '(echo hello)'
cargo run -- examples/hello.parsh world
```

不带参数启动时，如果标准输入是终端，parsh 会打开交互编辑器；否则从标准输入读取脚本。
`parsh -` 可以显式指定从标准输入读取。另提供 `--help` 和 `--version`。
脚本参数通过列表 `$args` 获取，其中不包含脚本文件名。
将可执行文件加入 PATH 后，脚本可以使用 `#!/usr/bin/env parsh` 作为首行。

命令行选项由 clap 解析。脚本路径或 `-c SOURCE` 之后的所有参数都会原样传入脚本，
包括 `--help` 和 `--`。如果脚本文件名以 `-` 开头，可使用 `parsh -- -script.parsh`。

## 变量与值

在值的位置，裸词表示文本：`123`、`true`、`false` 和 `nil` 都没有特殊的字面量含义。
双引号字符串支持 `\"`、`\\`、`\n`、`\r` 和 `\t` 转义，不支持变量插值。
读取变量值时使用 `$name`；绑定和赋值目标使用裸名字，包括函数参数、循环绑定和环境变量设置。
变量名以字母或 `_` 开头，后续可包含字母、数字和 `_`。绑定目标不接受引号字符串或表达式。

```lisp
(let name "a friend")
(echo hello $name)
(set name world)
(echo (str "hello, " $name))
(export EDITOR vim)
```

`let` 在当前词法作用域中绑定变量。`set` 更新最近的已有绑定，或已有的环境变量；
名称未定义时会报错。查找不到局部变量时，会继续查找继承的环境变量。
`export` 为后续子进程设置环境变量，并更新已有的同名局部绑定。
环境变量与工作目录的修改属于当前 parsh 会话。

```lisp
(let files (list "a file.rs" other.rs))
(printf "<%s>\n" $files)
(for file (glob *.rs)
  (echo $file))
```

列表作为外部命令参数时会展开一层。文本始终保持为一个参数，即使其中包含空格或换行。
`list` 构造列表，`str` 拼接标量值。`glob` 显式匹配文件，返回排序后的路径列表，
没有匹配项时返回空列表。普通裸词、字符串和变量值都不会隐式进行通配符展开、分词或波浪号展开。

`cd` 接受一个路径，不提供路径时使用 `$HOME`，并更新 `$PWD` 和 `$OLDPWD`。
相对命令路径、glob 模式和重定向路径均以当前工作目录为基准。

## 四则运算

裸词继续表示文本。`+`、`-`、`*`、`/` 和 `=` 接受数值或数值文本，
包括变量和捕获的命令输出。算术返回数值；普通文本 `00123` 仍保留原样。

```lisp
(let count (+ 001 2))
(+ $count 1)
(/ 5 2)
(eq $count 3)
(= $count 3.0)
(str 00123)
```

绑定之后，交互环境依次显示 `4`、`2.5`、`false`、`true` 和 `"00123"`。
`eq` 比较类型和值，文本、整数和浮点数互不相同。
`=` 比较数值，包括数值文本；它恰好接受两个参数，不引入浮点比较容差。

参数从左到右各求值一次，运算左结合。`+`、`*` 支持任意数量的参数，
`(+)` 返回整数 `0`，`(*)` 返回整数 `1`。
`-`、`/` 至少接受一个参数，单参数分别表示取负和取倒数。除法始终返回浮点数。

数值文本去掉首尾空白后完整解析，支持正负号、十进制整数、小数和科学计数法。
前导零按十进制处理，整数文本必须在 `i64` 范围内。布尔值、nil 和列表不能参与运算。
整数加减乘保持精确并检查溢出；每步运算遇到浮点数时使用 `f64`，
可能损失大整数精度，也有普通浮点舍入误差，例如 `(+ 0.1 0.2)` 返回
`0.30000000000000004`。非法操作数、除零、整数溢出和非有限浮点数均为语言错误，退出码为 `2`。
数值显示不加引号，浮点数保留小数点或指数，例如 `4.0`。
`str`、命令参数和环境变量使用相同格式。文件和 `-c` 脚本需要用 `echo` 等命令显式打印结果。

## 结构化注释

```lisp
(; 这是一个完整的注释表达式。
   (; 注释可以嵌套。 )
   (no-such-command $undefined)
)

(echo (; 这个注释不会产生参数。 ) hello)
(echo ; this;is;text)
```

首个裸词为 `;` 的列表会被 reader 丢弃，无论它出现在什么位置。
注释内容仍遵循字符串与括号配平规则，但不会求值，也不会检查名称是否已定义。
其他位置的 `;` 都是普通文本；没有行注释。带引号的 `";"` 不是注释标记。

## 命令与组合

命令依次查找内置形式、命名函数和 PATH 中的程序。
外部程序直接启动，表达式不会交给另一个 Shell 解析。
命令名也可以来自文本变量，例如 `($EDITOR file.txt)`；
变量值作为一个完整的程序名使用，不会隐式拆分出参数。

```lisp
(echo (pwd))
(| (find . -name "*.rs") (sort))
(|> files.txt (| (find . -name "*.rs") (sort)))
(|>> log.txt (echo another entry))
(<| input.txt (sort))
(|2> errors.txt (grep needle missing.txt))
```

组合操作如下：

- `|`：将外部命令连接为管道。
- `|>`、`|1>`：创建或清空文件，并将标准输出重定向到该文件。
- `|>>`、`|1>>`：创建文件或追加内容，并将标准输出重定向到该文件。
- `<|`：从文件读取标准输入。
- `|2>`：创建或清空文件，并将标准错误重定向到该文件。
- `|2>>`：创建文件或追加内容，并将标准错误重定向到该文件。

重定向始终将路径作为第一个参数、表达式作为第二个参数。
重定向形式可以嵌套，也可以包裹整个管道。
首版管道的每个阶段必须是外部命令调用；函数和改变 Shell 状态的内置形式在管道外执行。

例如，将标准输出写入清空后的日志，并将标准错误追加到另一个日志：

```lisp
(|1> output.log
  (|2>> errors.log
    (make)))
```

顶层命令实时输出。外部命令或管道用作值时，会将标准输出按 UTF-8 捕获，
移除末尾的 LF 换行符，并将结果保持为一个参数。标准错误仍写入原来的目标。
二进制输出应使用管道或文件重定向。显式重定向优先于对该表达式输出的捕获。

## 控制流与函数

```lisp
(defn greet (name)
  (echo hello $name))

(if (test -d src)
    (greet developer)
    (echo missing))

(if (eq $EDITOR vim)
    (echo using vim))

(if (not (test -f config.txt))
    (echo configuration missing))

(do
  (let message "multiple expressions")
  (echo $message))
```

`if` 只对选中的分支求值。条件必须产生布尔值（来自 `eq`、`=` 或 `not`）或命令退出状态；
退出状态为零表示真。文本和数值不会隐式转换为布尔值。
`do` 在当前作用域中依次执行表达式。
`for` 对列表求值，并为每次迭代创建新的词法绑定。

函数名和参数声明使用裸名字；读取参数和局部变量的值时使用 `$name`。
函数捕获定义时的词法作用域，并返回最后一个表达式的值。
参数表达式在绑定形参之前求值。函数既可以返回命令输出，也可以返回数值、列表和布尔值。
函数用作值时，会捕获整个函数体的标准输出：如果最后一个表达式产生命令退出状态，
则返回捕获的输出文本；否则直接返回最后一个表达式的值，此前捕获的输出不再显示。

普通命令返回非零退出状态时，当前脚本或粘贴批次停止执行。
条件位置允许检查非零退出状态，但程序不存在等启动错误仍会导致失败。
管道返回最右侧失败阶段的非零退出状态，即使最后一个阶段成功也一样，包括上游因 SIGPIPE 退出的情况。
所有阶段的子进程都会被回收。
`exit` 接受 0 到 255 的退出码，并立即退出，即使它位于函数或嵌套表达式中；默认退出码为 0。

## 交互编辑与粘贴

- 提示符 `(` 提供最外层左括号。Enter 插入换行；手动输入 `)` 时，
  光标左侧（包含刚输入的 `)`）构成完整表达式即提交。
  内层括号，以及字符串或注释中的括号不会触发提交。
  输入为空白时，隐含的 `(` 显示为灰色；开始输入表达式后恢复原色。
  显式输入的 `(` 使用原色。
- 在编辑区中间提交时，右侧文本原样保留为下一条草稿，光标停在草稿开头。
  右侧不会自动执行；左侧求值报错时也会保留草稿。此行为仅适用于手动输入 `)`，
  粘贴仍按下面的批次规则处理。
- 新输入以 `(` 开头时，会切换到显式源码模式，提示符提供的隐含左括号消失。
  因此粘贴完整脚本时，脚本自身的括号只会显示和读取一次。
- bracketed paste 内容按顺序处理。每个完整表达式都会先执行，再处理剩余内容。
  第一个表达式之后，同一批粘贴的剩余内容按显式源码读取，不会重新补上隐含左括号。
  末尾未完成的表达式会保留，供继续编辑。
- 每个多余的顶层 `)` 都会单独报告带位置的错误，并被消耗掉；后续合法表达式继续执行。
  例如，`(echo a))) (echo b)` 会输出 a、报告两次错误，再输出 b。
- 运行失败会停止该批次后续表达式的求值，但 reader 仍会继续报告已收到源码中的多余右括号。
  Ctrl+C 取消当前任务及其粘贴批次的剩余内容。
- 剩余粘贴源码保留在 parsh 的队列中；交互式子进程读取后续的终端输入，不会读取该队列中的源码。
- 方向键、Home/End、Backspace/Delete、Ctrl+A/E 和 Ctrl+U/K 用于编辑文本。
  编辑与显示会考虑 Unicode 字素簇及字符宽度。
  Up/Down 在行间移动，并在编辑区边界调取会话历史；Ctrl+P/N 始终用于浏览历史。
- Tab 补全内置命令、已定义函数、可执行程序、文件路径和 `$变量名`。
  唯一匹配直接补全，目录以 `/` 结尾；多个匹配先补公共前缀，再按 Tab 显示候选。
  补全作用于光标所在词，支持带引号的路径，不会执行命令。
  `cd` 只补目录，隐藏文件需要输入 `.` 前缀；字符串内不展开变量，结构化注释中不补全。
  粘贴中的制表符保持原样。
- 历史记录保存完整源码。调取时，编辑区会去掉最外层的一个 `)`，光标移到末尾。
  可直接追加参数，或按 `)` 重新执行；向下浏览回到原草稿时，草稿原样恢复。
- Ctrl+C 清空输入或中断前台任务。编辑区为空时 Ctrl+D 退出，否则删除光标后的字符。

### Emacs 风格快捷键

原生终端和网页体验终端共用以下编辑命令。Alt 组合键也可以先按 Esc，再按对应键。
字符编辑以 Unicode 字素簇为单位；Home/End、Ctrl+A/E 和 Ctrl+U/K 作用于当前逻辑行。

| 按键 | 操作 |
| --- | --- |
| Ctrl+B/F、Ctrl+H | 向左/右移动；向前删除 |
| Alt+B/F | 移到上一个词的开头/下一个词的末尾 |
| Ctrl+W | 向后剪切，空白分隔词 |
| Alt+Backspace、Alt+D | 向后/向前剪切，字母数字组成词，路径标点和下划线是分隔符 |
| Ctrl+U/K | 剪切到行首/行尾；行尾处 Ctrl+K 剪切换行符 |
| Ctrl+Y、Alt+Y | 粘回剪切内容；紧接着轮换此前剪切的内容 |
| Ctrl+T | 交换相邻字素簇；行尾交换最后两个，不跨越换行 |
| Ctrl+L | 清屏并重绘，保留草稿和会话 |
| Ctrl+R/S | 向后/向前增量搜索会话历史 |
| Ctrl+_、Ctrl+X Ctrl+U | 撤销一组编辑 |

连续剪切会按方向合并到同一条剪切记录，移动或其他编辑命令结束合并。
剪切记录跨命令保留，重置会话时清空；Alt+Y 仅紧接 Ctrl+Y 或 Alt+Y 时有效。
粘回、交换和撤销只编辑文本，其中的 `)` 不会自动执行命令。

搜索区分大小写，按完整历史源码匹配子串，不循环；输入或粘贴更新查询，Backspace 删除一个字素簇。
再次按 Ctrl+R/S 查找上一个/下一个匹配项；空查询时再次按下会复用上次查询。
未匹配时显示失败提示并保留上次预览。Enter 或 Esc 接受结果并回到编辑，不执行也不插入换行；
之后按 `)` 执行。Ctrl+G 恢复搜索前的草稿和光标；其他编辑命令接受结果后继续操作，
Ctrl+L 保留搜索，Ctrl+C 取消输入。

连续打字按组撤销；删除、剪切、粘回、交换、补全和未提交的粘贴各自是一组。
移动光标结束打字分组；历史切换、搜索确认和提交建立新基线，中断或清空输入也会清空撤销记录。
撤销不会恢复已经执行的命令或其副作用。

网页快捷键只在终端聚焦时生效。浏览器或操作系统保留的组合键可能无法交给页面；
Alt 键冲突时可使用 Esc 前缀。复制和粘贴继续使用浏览器的快捷键。

错误信息包含来源、行号和列号。脚本执行时也会恢复多余顶层 `)` 的错误，并继续执行后续表达式。
这类错误会使脚本以状态码 2 退出，除非后续的运行失败或显式 `exit` 指定了其他退出状态。
命令失败保留其退出状态；程序不存在时使用 127，没有执行权限时使用 126，其他语言错误使用 2。

首版面向 Linux 前台任务，包括交互式外部程序和前台管道。
暂不支持后台作业表、`bg`、`fg` 或挂起与恢复；子进程忽略 Ctrl+Z。
历史记录仅在当前会话中保留。宏和持久化配置留待后续实现。
