# parsh

English | [简体中文](README.zh-CN.md)

parsh (**parenthesis shell**) is a Linux shell whose interactive commands and
scripts share the same Lisp dialect.

[Website & playground](https://jmjoy.github.io/parsh/en/) ·
[Documentation](https://jmjoy.github.io/parsh/en/docs/)

See the documentation for getting started, the language reference, examples, and
development guides.
