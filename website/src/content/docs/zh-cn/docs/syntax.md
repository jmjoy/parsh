每次调用都是括号包裹的表达式。内层调用先求值，再作为参数传入：

```parsh
(str "hello, " (str "a " "friend"))
(list one "two words" (eq a a))
```

在值的位置，裸词表示文本：`123`、`true`、`false` 和 `nil` 都没有特殊的字面量含义。
双引号字符串支持 `$name` 和 `$(...)` 插值，以及 `\"`、`\\`、`\n`、`\r`、`\t` 和 `\$` 转义。
单引号字符串完全保留原文，不插值也不处理转义。`${name}` 保持为普通文本。
读取变量值时使用 `$name`；绑定和赋值目标使用裸名字，包括函数参数、循环绑定和环境变量设置。

reader 读取文本、变量引用、插值字符串和表达式列表。求值可以返回文本、数值、布尔值、列表、映射、nil 或原生命令状态。它们是不同的类型；裸词 `true` 和 `nil` 本身仍然只是文本。

```parsh
(eq true true)
(not (eq a b))
(list a "b c" (eq x x))
```

交互返回值依次为 `true`、`true` 和 `("a" "b c" true)`。文本以引号与转义形式显示；nil 不显示。文件和 `-c` 脚本不会自动打印返回值。

`(map name parsh)` 构造映射，显示为 `(map "name" "parsh")`。
映射使用文本键并保留插入顺序，构造、读取与修改方式见[映射](/parsh/zh-cn/docs/variables/#映射)。

## 集合语法糖

`[...]` 是 `(list ...)` 的简写，`{...}` 是 `(map ...)` 的简写：

```parsh
[]
[one "two words" (eq a a)]
{}
{name parsh items [one two] nested {enabled (eq a a)}}
(let items [a (; 忽略这段注释) b])
```

元素以空白分隔。映射使用交替的键和值，沿用 `map` 的文本键和重复键规则。
元素、键和值从左到右各求值一次。集合可以嵌套，并用于任何允许调用表达式的位置。
交互返回值沿用现有格式：`("one" "two words" true)` 和 `(map ...)`。

三种括号 `()`、`[]`、`{}` 都必须配对，包括结构化注释内部。
只有 `(; ...)` 表示注释；`[; a]` 包含两个文本值。
字符串外的方括号和花括号即使没有相邻空白也会分隔表达式。
包含它们的字面文本和 glob 模式需要加引号，例如 `(glob 'file[12].txt')`。
字符串内的方括号和花括号保持为普通文本，`${name}` 仍然是字面文本。

提示符中可以直接输入或粘贴集合。按 Enter 时，如果补入一个匹配的 `]` 或 `}`
就能使整个输入完整，会自动补入并提交；未完成的嵌套结构会继续换行。
灰色闭括号在提交前只参与显示。

## 字符串与插值

```parsh
(let name parsh)
(str "hello, $name")
(str "$(get name)_suffix")
(str "sum=$(+ 1 2)")
(str "nested=$(str "a" 'b')")
(str "cwd=$(pwd)")
(str '$name $(+ 1 2)\n')
(str "\$name \$(+ 1 2)")
```

`$name` 读取最长的合法变量名。变量名后紧接 `_suffix` 等文本时，使用 `$(get name)` 明确边界。
`${name}` 没有特殊含义；不构成变量名或 `$(` 开头的 `$` 保持为文本。

`$(...)` 中的括号就是普通调用表达式。`$(name)` 调用名为 `name` 的零参数函数或命令；
`$(get name)` 读取变量。支持所有现有表达式，包括嵌套调用、控制流及结构化注释。
内层字符串按正常 parsh 语法书写，不需要额外为外层转义。`pwd` 示例需要命令执行后端。

各片段在当前作用域中从左到右求值一次，副作用与错误规则与普通调用相同。
标量按 `str` 的规则转换：数值、布尔值转文本，nil 转空文本，列表和映射报错。
外部命令捕获 UTF-8 标准输出并移除末尾 LF 换行符，标准错误保留原来的输出目标。
错误会停止当前批次。整个结果保持为一个参数，插入的值不会再次解析或插值。

普通单引号保留直到下一个单引号之间的全部内容，包括反斜杠、美元符和换行。
需要单引号字符时使用双引号。相邻的引号字符串和裸词表达式不会自动拼接。
要把字面 `$name` 或 `$(...)` 传给 `sh -c` 等其他程序，使用单引号或以 `\$` 转义美元符。
文本显示也会转义美元符，避免复制显示的字符串时触发插值。

三引号允许在内容中直接放入单个或两个同类引号。
`"""..."""` 支持与普通双引号相同的插值和转义，`'''...'''` 完全保留原文：

```parsh
(str """hello, "$name"
sum=$(+ 1 2)""")
(str '''literal '$name'
$(pwd)\n''')
```

所有换行、缩进及首尾空白都会保留，包括起始分隔符后紧接的换行。
只有连续三个同类引号才结束字符串。三重双引号中的 `\"` 仍会转义引号，
因此 `\"""` 可以插入三个字面双引号。连续六个同类引号表示空字符串。
相邻字符串仍然是独立表达式。

## 四则运算与数值比较

`123` 在数值运算解析之前仍是文本。算术运算符 `+`、`-`、`*`、`/`
和比较运算符 `=`、`!=`、`<`、`<=`、`>`、`>=`
接受运行时数值或数值文本。变量和捕获的命令输出与裸词、引号字符串使用同一套规则。

| 表达式 | 交互返回值 |
| --- | --- |
| `(+ 123 2)` | `125` |
| `(+ "1.5" 2)` | `3.5` |
| `(/ 5 2)` | `2.5` |
| `(/ 8 2)` | `4.0` |
| `(str 00123)` | `"00123"` |
| `(eq (+ 1 2) 3)` | `false` |
| `(eq (+ 3) (+ 3.0))` | `false` |
| `(= (+ 1 2) 3)` | `true` |
| `(= 001 1.0)` | `true` |
| `(!= 1 1.5)` | `true` |
| `(< 2 10)` | `true` |
| `(<= 3 3.0)` | `true` |
| `(> 10 2)` | `true` |
| `(>= 2.5 3)` | `false` |

文本去掉首尾空白后必须完整解析。支持 `+001`、`-12`、`.5`、`1.` 和 `2.5e1` 等写法。
整数使用 `i64`；带小数点或指数时使用 `f64`。前导零按十进制处理，不表示八进制。
超出范围的整数文本直接报错，不会改为浮点数。布尔值、nil、列表和映射不能作为数值使用。

参数从左到右各求值一次，算术运算左结合。`+`、`*` 接受任意数量的参数，
`(+)` 返回整数 `0`，`(*)` 返回整数 `1`。
`-`、`/` 至少接受一个参数；`(- 5)` 返回 `-5`，`(/ 4)` 返回 `0.25`。
整数加减乘检查溢出，每步运算遇到浮点数时使用 `f64`；除法始终返回浮点数。
后面的浮点参数不能避免前面的整数运算溢出。

`eq` 按类型和值比较，包括列表和映射中的元素；映射的插入顺序不影响比较。数值比较 `=` 判断相等，`!=` 判断不相等；
`<`、`<=`、`>`、`>=` 分别判断小于、小于等于、大于、大于等于。
每个数值比较运算符恰好接受两个参数，返回布尔值，可解析数值文本。
整数与浮点数按数值比较，混合比较时仍保留整数精度，
例如 `(> 9007199254740993 9007199254740992.0)` 返回 `true`。
浮点比较是精确比较，不引入容差：由于 `f64` 的二进制舍入误差，
`(= (+ 0.1 0.2) 0.3)` 返回 `false`。涉及浮点数的算术也可能损失大整数精度。

```parsh
(let count (+ 1 2))
(if (>= $count 3) (str "at least three") (str fewer))
```

数值显示不加引号。浮点数保留小数点或指数，包括 `4.0` 和 `-0.0`；
`str`、外部命令参数和环境变量使用相同格式。捕获命令输出或导出数值会重新得到文本。
数值不会隐式转换为布尔值；在条件中使用数值比较。
非法操作数、除零、整数溢出和非有限浮点数会在出错的操作数处报告语言错误，退出码为 `2`。

## 结构化注释

```parsh
(; 这是一个完整的注释表达式。
   (; 注释可以嵌套。 )
   (no-such-command $undefined)
)

(echo (; 这个注释不会产生参数。 ) hello)
(echo ; this;is;text)
```

首个裸词为 `;` 的列表会被 reader 丢弃，无论它出现在什么位置。
注释内容仍遵循字符串与括号配平规则，但不会求值，也不会检查名称是否已定义。
其他位置的 `;` 都是普通文本；没有行注释。带引号的 `";"` 不是注释标记。
