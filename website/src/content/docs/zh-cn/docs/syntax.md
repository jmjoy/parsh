title: "语法与值"
description: "裸词、字符串、值的类型与结构化注释。"
---

每次调用都是括号包裹的表达式。内层调用先求值，再作为参数传入：

```parsh
(str "hello, " (str "a " "friend"))
(list one "two words" (eq a a))
```

在值的位置，裸词表示文本：`123`、`true`、`false` 和 `nil` 都没有特殊的字面量含义。
双引号字符串支持 `\"`、`\\`、`\n`、`\r` 和 `\t` 转义，不支持变量插值。
读取变量值时使用 `$name`；绑定和赋值目标使用裸名字，包括函数参数、循环绑定和环境变量设置。

reader 读取文本、变量引用和表达式列表。求值可以返回文本、布尔值、列表、nil 或原生命令状态。它们是不同的类型；裸词 `true` 和 `nil` 本身仍然只是文本。

```parsh
(eq true true)
(not (eq a b))
(list a "b c" (eq x x))
```

交互返回值依次为 `true`、`true` 和 `("a" "b c" true)`。文本以引号与转义形式显示；nil 不显示。文件和 `-c` 脚本不会自动打印返回值。

## 结构化注释

```parsh
(; 这是一个完整的注释表达式。
   (; 注释可以嵌套。 )
   (no-such-command $undefined)
)

(echo (; 这个注释不会产生参数。 ) hello)
(echo ; this;is;text)
```

首个裸词为 `;` 的列表会被 reader 丢弃，无论它出现在什么位置。
注释内容仍遵循字符串与括号配平规则，但不会求值，也不会检查名称是否已定义。
其他位置的 `;` 都是普通文本；没有行注释。带引号的 `";"` 不是注释标记。
