---
title: "错误与退出码"
description: "源码位置、批次失败与原生退出状态。"
---

诊断包含来源、行号与列号：

```text
interactive:1:6: undefined variable $missing
```

普通命令返回非零退出状态时，当前脚本或粘贴批次停止执行。
条件位置允许检查非零退出状态，但程序不存在等启动错误仍会导致失败。
管道返回最右侧失败阶段的非零退出状态，即使最后一个阶段成功也一样，包括上游因 SIGPIPE 退出的情况。
所有阶段的子进程都会被回收。
`exit` 接受 0 到 255 的退出码，并立即退出，即使它位于函数或嵌套表达式中；默认退出码为 0。

遇到顶层多余右括号时，reader 消耗这个字符、报告错误并继续读取。读取错误使脚本退出码为 2，运行时失败或显式退出可以覆盖它。命令不存在时使用 127，权限不足时为 126，其他语言错误为 2。

浏览器中，错误停止当前粘贴批次，后续新输入仍可执行。原生专属操作会给出能力限制提示。会话退出后，可用重置按钮重新开始。
